# サンプル画像の配置ルール

index.html と同じ階層（リポジトリ直下）に、以下のファイル名で画像を置いてください。
サブフォルダは不要です。コード側の変更も不要です。

ファイル名形式:
{mode}-{stage}.jpg

mode:  insect | plant | fossil | artifact
stage: original | lasso | feature | edge | handfix

例:
insect-original.jpg
insect-feature.jpg
insect-edge.jpg
insect-handfix.jpg
plant-original.jpg
...

画像が未配置の組み合わせは、代わりに insect-original.jpg が仮画像として表示されます。
